# Gestor de tareas personales

## Descripcion
Este es un proyecto basico desarrollado en Python. Permite registrar tareas y visualizar la lista de tareas ingresadas.

## Requisitos
- Python 3 instalado.
- Visual Studio Code (opcional, para editar el codigo).

## Como ejecutar
1. Abre la carpeta del proyecto en Visual Studio Code.
2. Abre una terminal.
3. Ejecuta el comando:

```bash
python main.py
```

## Funciones iniciales
- Agregar una tarea.
- Mostrar las tareas registradas.
- Salir del programa.
